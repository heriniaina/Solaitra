To configure Firebase Storage backups, follow these steps:

### 1. Download Firebase Service Account Credentials JSON

1. Go to the Firebase Console: https://console.firebase.google.com/
2. Select your project.
3. Click on the Gear icon next to "Project Overview" in the left sidebar and select **Project Settings**.
4. Go to the **Service accounts** tab.
5. Click the **Generate new private key** button at the bottom of the page.
6. A `.json` file containing your credentials will automatically download.
7. Rename this file to `google-service-account.json` and place it in the `modules/` directory of the application:
   `modules/google-service-account.json`
   *(Alternatively, you can set the file path in your environment using the `FIREBASE_SERVICE_ACCOUNT_JSON` variable, or specify the JSON raw content in `FIREBASE_SERVICE_ACCOUNT_JSON_CONTENT`).*

### 2. Retrieve your Firebase Storage Bucket Name

1. In the left navigation sidebar of the Firebase Console, go to **Build** > **Storage**.
2. If Storage is not enabled, click **Get Started** and follow the prompts to configure it.
3. Once enabled, copy the bucket URL from the top of the files tab (looks like `gs://project-id.appspot.com` or `gs://project-id.firebasestorage.app`).
4. Copy only the domain name part (e.g. `project-id.appspot.com` or `project-id.firebasestorage.app` - omit `gs://`).

### 3. Configure the Environment Variables

Add the following variables to your environment configuration (your `.env` file):

```env
# Firebase Storage Bucket Name
FIREBASE_BUCKET_NAME=project-id.appspot.com
```

### 4. Running the CLI Backup Command

To run the backup manually from the command line:

```bash
php spark db:backup-firebase
```

This will export your database, compress it to `.sql.gz`, and upload it to Firebase Storage.
